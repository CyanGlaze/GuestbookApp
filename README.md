# 礼金账本小程序

一个用于管理礼金账本的微信小程序，支持导入Excel、智能搜索、编辑管理等功能。

## 功能特点

1. **微信授权登录** - 使用微信头像和昵称快速登录
2. **Excel导入** - 支持 .xlsx / .xls 格式的账本导入
3. **书架管理** - 像小说书架一样展示账本，两排显示
4. **智能搜索** - 支持姓名、拼音、地址搜索
5. **编辑管理** - 长按编辑、复制、删除记录
6. **数据备份** - 支持导出和导入备份

## 使用说明

### 1. 导入项目

1. 下载微信开发者工具
2. 导入 `miniprogram` 文件夹
3. 在 `project.config.json` 中修改 `appid` 为你的小程序 AppID

### 2. 添加图标

在 `images` 文件夹中添加以下图标（建议尺寸 81x81 像素）：

- `shelf.png` - 书架图标（未选中）
- `shelf-active.png` - 书架图标（选中）
- `mine.png` - 我的图标（未选中）
- `mine-active.png` - 我的图标（选中）
- `wechat.png` - 微信图标（登录页使用）

或者使用在线图标生成工具创建。

### 3. 安装完整版 XLSX 库（推荐）

当前项目使用简化版的 xlsx 解析库，功能有限。建议安装完整版：

```bash
# 在 miniprogram 目录下执行
npm init -y
npm install xlsx-js-style
```

然后修改 `utils/xlsx.mini.js` 为：

```javascript
const XLSX = require('xlsx-js-style');
module.exports = XLSX;
```

### 4. Excel 文件格式

导入的 Excel 文件应包含以下列：

| 姓名 | 礼金 | 地址 | 备注 |
|------|------|------|------|
| 张三 | 200  | 北京市 | 婚礼 |
| 李四 | 500  | 上海市 | 生日 |

## 页面说明

### 登录页面
- 首次使用需要授权登录
- 选择微信头像并输入昵称

### 书架主页
- 展示所有账本，两排显示
- 点击账本进入详情
- 长按账本可编辑、复制、删除
- 点击"+"添加新账本

### 账本详情页
- 显示所有礼金记录
- 支持拼音搜索
- 右侧字母索引快速定位
- 长按记录可编辑、复制、删除
- 点击右下角"+"添加新记录

### 个人中心
- 导入新账本
- 导出/导入备份
- 查看数据统计
- 退出登录

## 注意事项

1. 数据存储在本地，清除小程序数据会丢失所有记录
2. 建议定期使用导出备份功能保存数据
3. 完整版 xlsx 库支持更多 Excel 格式和功能

## 技术栈

- 微信小程序原生开发
- XLSX.js (Excel解析)
- 拼音匹配算法
